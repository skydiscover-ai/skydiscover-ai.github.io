Getting Started

Three Lines to Discovery

Python
from skydiscover import run_evolution

result = run_evolution(
    initial_program="program.py",
    evaluator="evaluator.py",
    search="adaevolve",  # or evox, openevolve, gepa, shinkaevolve...
    model="gpt-5",
    iterations=100,
)
print(result.best_score, result.best_code)

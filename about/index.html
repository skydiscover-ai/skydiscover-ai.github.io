About SkyDiscover

A flexible, modular framework for AI-driven scientific and algorithmic discovery.

What is SkyDiscover?

SkyDiscover is an open-source framework for LLM-driven evolutionary search. You give it a program and an evaluator — it iteratively mutates the program, scores each variant, and keeps improving. The framework supports multiple search algorithms, external backends, and nearly 200 real-world optimization tasks.

It was built to solve a fundamental problem in the AI-driven discovery space: existing frameworks like OpenEvolve, GEPA, and ShinkaEvolve tightly couple their components, making it hard to reuse, extend, or compare approaches. SkyDiscover provides a modular architecture where each component can be swapped independently.

Why SkyDiscover?

  • Modular: Four reusable components (Guide, Prompt Builder, Solution Generator, Evaluator) that can be swapped independently.
  • Flexible: Works with any OpenAI-compatible LLM, any language, and any evaluator you write.
  • Unified: Compare algorithms on shared benchmarks — built-in and external — with one interface.
  • Low overhead: New algorithms take <2k LoC on top of the shared ~8k LoC backbone.
  • Production-ready: Checkpointing, resuming, live monitoring, human-in-the-loop steering.

Key Capabilities

Built-in Search Algorithms

  • AdaEvolve — Adaptive multi-island evolution with bandit-based scheduling
  • EvoX — Co-evolves the search strategy alongside the solution
  • TopK — Simple, fast baseline that keeps top-K programs
  • Beam Search — Structured exploration over program space
  • Best-of-N — Generates N variants, keeps the best

External Backends

  • OpenEvolve — Google's evolutionary coding framework
  • ShinkaEvolve — Sakana AI's async evolutionary engine
  • GEPA — Reflection-guided prompt evolution

Live Dashboard

Watch evolution unfold in real time with scatter plots, code diffs, AI-powered summaries, and human-in-the-loop feedback. No restart needed to steer the search.
